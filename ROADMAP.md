# FootwearX Product Roadmap

**Core Philosophy:** "The easiest billing + stock app for a footwear shop."
**Target Audience:** Small Indian footwear shop owners.
**Key Tenet:** Hide ERP complexity (SKUs, ledgers, variants) behind simple, retail-focused terminology.

## Phase 1 — Must Have (Current Focus)

- [x] **1. Mobile-first redesign**
  - Shift from dense desktop layouts to mobile-friendly touch interfaces
  - Bottom navigation (Home | Billing | Products | Stock | More)
- [x] **2. Extremely simple navigation**
  - Use simple terminology (e.g., Billing instead of POS, Stock Update instead of Adjustment)
- [x] **3. Fast POS**
  - Streamline billing flow: Search/Scan -> Size -> Cart -> Collect Payment
- [x] **4. Better product/size matrix**
  - Simplify product creation, make barcodes and custom SKUs optional
  - "Stock by size" views everywhere
- [x] **5. Customer selection in POS**
  - Quick walk-in vs. phone number lookup
- [x] **6. Split payment**
  - E.g., Cash + UPI for a single bill
- [x] **7. WhatsApp bill sharing**
  - Action to share bill after checkout
- [x] **8. Better returns**
  - Simple selection of previously billed items for return
- [x] **9. Profit calculation**
  - Sales - Cost - Discount = Gross Profit
- [x] **10. Expense tracking**
  - Track rent, electricity, staff salary, etc. to calculate Net Profit

## Phase 2 — Powerful Shop Features

- [x] **11. Credit / Udhaar** (Customer balances, due dates, payment collection)
- [x] **12. Stock ageing** (Identify dead stock: 0-30 days, 30-60, 90+)
- [x] **13. Size-wise sales** (Identify fast-moving sizes)
- [ ] **14. Reorder suggestions** (Stock decision support)
- [x] **15. Dead-stock report**
- [x] **16. Supplier balances**
- [x] **17. Customer purchase history**
- [ ] **18. Barcode scanning**
- [ ] **19. Thermal printing** (58mm/80mm support)
- [ ] **20. GST improvements** (Optional GST settings, HSN, Tax Invoice vs Bill of Supply)

## Phase 3 — Differentiators

- [ ] **21. Offline POS + sync**
- [ ] **22. WhatsApp reminders**
- [ ] **23. Automatic low-stock alerts**
- [ ] **24. Daily owner summary**
- [ ] **25. AI business insights**
- [ ] **26. Multi-shop support**
- [ ] **27. Cloud backups/export**
- [ ] **28. Staff activity tracking**
